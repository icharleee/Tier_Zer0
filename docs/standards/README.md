# Implementation Standards

Standards define *how* recurring implementation concerns are handled, so ADRs record decisions without bloating into manuals. Standards are governed documents: semantically versioned per the [Governance Versioning Standard](GOVERNANCE_VERSIONING_STANDARD.md), written in [Lexicon](../glossary/LEXICON.md) vocabulary, and always subordinate to the [Engineering Constitution](../foundation/ENGINEERING_CONSTITUTION.md).
