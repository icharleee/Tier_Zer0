# The ARGUS Knowledge Corpus

Institutional knowledge, consolidated per [ADR-0012](../adr/0012-consolidate-knowledge-corpus.md). ARGUS keeps knowledge, not just code; this corpus is where it lives:

| Directory | Contents |
|---|---|
| [`academy/`](academy/README.md) | Self-service onboarding curriculum — every new engineer should be able to learn ARGUS without asking another engineer |
| [`research/`](research/README.md) | Investigation Systems Science (ISS) papers — the project's scientific corpus |
| [`standards/`](standards/README.md) | Implementation standards — how recurring concerns are handled, so ADRs stay decisions |

Deliberately **not** in this corpus: the [Lexicon](../glossary/LEXICON.md) (normative governance vocabulary), the foundation documents, the ADR record, and the domain/architecture layers.
